# Abhishek Kamal — QA & SDET Career Hub

A lightweight, responsive starter website for a personal QA/SDET brand.

## Included

- Responsive homepage
- About section
- QA automation services
- Resume/LinkedIn services
- Mentoring & mock interviews
- AI/LLM testing service
- Free resources section
- Portfolio section
- Contact section
- Mobile navigation
- Dark developer-style visual design

## Customize before publishing

Search and replace:

- `hello@example.com` → your email
- `https://www.linkedin.com/` → your LinkedIn profile
- `https://www.youtube.com/` → your YouTube channel
- Placeholder project descriptions → your real projects
- Experience/statistics → verified figures you want to publish

## Run locally

Because this is a static site, you can simply open `index.html`.

For a better local development experience:

```bash
python -m http.server 8000
```

Then open:

http://localhost:8000
